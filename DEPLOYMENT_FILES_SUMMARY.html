Quick Start Guide

  1. Prepare ZIP File: ZIP your project (exclude vendor/, node_modules/, .env, storage/logs/*)
  2. Upload to Server: Use cPanel File Manager to upload and extract
  3. Create Database: In cPanel > MySQL Databases, create database and user
  4. Configure .env: Copy .env.production to .env and update database credentials
  5. Run Installer: Open https://yourdomain.com/setup.php in browser
  6. Set Permissions: storage/ and bootstrap/cache/ need 755 permissions
  7. Create .htaccess: Rename .htaccess.example to .htaccess
  8. Test: Login with admin@ceylonpos.lk / admin123
  9. Secure: DELETE setup.php and change default passwords!

File Details

1. setup.php

SECURITY WARNING: This file MUST be deleted after installation!

This is the main installer that replaces all SSH commands. It performs:

  • System requirements check (PHP version, extensions)
  • Database connection test
  • Composer dependencies installation
  • Application key generation
  • Database migrations
  • Database seeding (default users, categories, etc.)
  • Storage link creation
  • Application optimization

2. DEPLOYMENT_GUIDE.html

Complete step-by-step guide covering:

  • Server requirements
  • cPanel database setup
  • File upload via File Manager
  • Environment configuration
  • Running the installer
  • SSL/HTTPS setup
  • Troubleshooting common problems

3. .env.production

Template configuration file with clearly marked placeholders:

  • Application settings (name, URL, debug mode)
  • Database credentials
  • Session and cache settings
  • Email configuration (optional)
  • POS-specific settings (currency, timezone)

4. .htaccess.example

Security and routing configuration:

  • Redirects all requests to public folder
  • Blocks access to sensitive files (.env, composer files)
  • Blocks direct access to application directories

Hosting Provider Compatibility

This deployment method works with any hosting that provides:

  • cPanel or similar control panel
  • PHP 8.1+ support
  • MySQL/MariaDB database
  • File Manager access

Tested with: Hostinger, Namecheap, SiteGround, Bluehost, GoDaddy, and most local Sri Lankan hosting providers.
