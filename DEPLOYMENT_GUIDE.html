Pure POS

Live Server Deployment Guide

Browser-Only Method - No SSH/Command Line Required

About This Guide
This guide will help you deploy Pure POS to a live hosting server so your clients can access it from anywhere via the internet. No SSH, command line, PowerShell, or root access is required - only a web browser and cPanel file manager.
0

Prerequisites - Requirements

Hosting Requirements:

  • cPanel access (Shared hosting, VPS, or dedicated server)
  • PHP 8.1 or higher
  • MySQL 8.0 or MariaDB 10.3+
  • Minimum 256MB PHP memory limit
  • Storage: 500MB+ (files + database)
Required PHP Extensions
Most hosting providers have these enabled by default: BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML, GD, Zip

Prepare Files (On Your Local Computer)

1.1 Create a ZIP archive of your project:

  1. Open your project folder
  2. Select all files and folders
  3. Right-click > "Send to" > "Compressed (zipped) folder"
  4. Name it pure-pos.zip
IMPORTANT - Do NOT Include These Files/Folders in ZIP!
  • vendor/ folder - (Will be installed on server)
  • node_modules/ folder - (Not needed)
  • .env file - (Will create production version on server)
  • storage/logs/*.log files
  • storage/framework/cache/* files
  • storage/framework/sessions/* files
  • storage/framework/views/* files

Files That MUST Be Included in ZIP:

pure-pos/ ├── app/ [OK] (Application code) ├── bootstrap/ [OK] ├── config/ [OK] ├── database/ [OK] ├── public/ [OK] (VERY IMPORTANT) ├── resources/ [OK] ├── routes/ [OK] ├── storage/ [OK] (empty subfolders only) ├── .env.production [OK] ├── artisan [OK] ├── composer.json [OK] ├── composer.lock [OK] ├── setup.php [OK] (INSTALLER SCRIPT) └── package.json [OK]

Create Database

3.1 Open MySQL Databases:

In cPanel, click the "MySQL Databases" icon.

3.2 Create New Database:

  1. In the "Create New Database" section
  2. Enter database name: pure_pos
  3. Click "Create Database" button
Note
cPanel automatically adds a prefix. Example: username_pure_pos
Write down this full name - you need it for the .env file!

3.3 Create Database User:

  1. Scroll to "MySQL Users" section
  2. Username: pos_user
  3. Password: Click "Password Generator" for a strong password
  4. Click "Create User"
  5. Copy and save the password somewhere safe!

3.4 Add User to Database:

  1. Go to "Add User To Database" section
  2. Select the user you created
  3. Select the database you created
  4. Click "Add"
  5. On the next page, check "ALL PRIVILEGES"
  6. Click "Make Changes"
Write Down These Details!
Database Name:username_pure_pos
Database User:username_pos_user
Database Password:your_generated_password
Database Host:localhost

Run Setup Script (Most Important Step!)

What This Does
The setup.php file performs all the tasks that normally require SSH commands: installing Composer packages, running database migrations, seeding default data, creating storage links, and optimizing the application.

6.1 Open setup.php in your browser:

https://yourdomain.com/setup.php

6.2 Follow the Setup Steps:

  1. Check Requirements - Verifies PHP version and extensions
  2. Install Dependencies - Installs Composer packages
  3. Generate App Key - Creates security encryption key
  4. Run Migrations - Creates database tables
  5. Seed Database - Adds default data (categories, users, etc.)
  6. Create Storage Link - Enables file uploads
  7. Finalize - Cleanup and optimization
If You Get Errors
  • Database Connection Error: Check .env database credentials
  • Permission Denied: Check storage/ folder permissions (Step 7)
  • Memory Error: Contact hosting support to increase PHP memory limit
  • Timeout Error: Refresh the page and continue from where it stopped

Set File Permissions

7.1 Set storage/ folder permissions:

  1. In File Manager, right-click on storage folder
  2. Click "Change Permissions"
  3. Set permission value to: 755 or 775
  4. Check "Recurse into subdirectories"
  5. Click "Change Permissions"

7.2 Set bootstrap/cache/ folder permissions:

Repeat the same process for bootstrap/cache folder with 755 permissions.

7.3 Set .env file permission:

  1. Right-click on .env file
  2. Click "Change Permissions"
  3. Set permission to: 644
Permission Numbers Explained
ValueMeaningUse For
755Read/Execute for all, Write for ownerFolders
644Read for all, Write for ownerConfig files
775Read/Write/Execute for owner/groupStorage folders
8

Configure Document Root (MUST DO!)

Security Warning!
For Laravel projects, only the public/ folder should be web-accessible. Without this configuration, your .env file and source code could be exposed!

Option A: .htaccess Method (Easiest)

Create a .htaccess file in the main folder (public_html):

<IfModule mod_rewrite.c>
    RewriteEngine On

    # Redirect all requests to public folder
    RewriteRule ^(.*)$ public/$1 [L]
</IfModule>

Option B: Change Document Root in cPanel (Better Security)

  1. Go to cPanel > "Domains" or "Subdomains"
  2. Click "Manage" or "Edit" for your domain
  3. Change Document Root to: /public_html/public
  4. Save changes
Need Help?
Contact your hosting provider's support via live chat. Say: "I need to change the document root to the public folder for my Laravel application"

Enable SSL Certificate (HTTPS)

10.1 Install Free SSL (Let's Encrypt):

  1. In cPanel, find "SSL/TLS Status" or "Let's Encrypt SSL"
  2. Select your domain
  3. Click "Issue" or "Run AutoSSL"
  4. Wait a few minutes for certificate installation

10.2 Force HTTPS Redirect:

Option 1: In cPanel > "Domains" > Enable "Force HTTPS Redirect"

Option 2: Add this to the top of public/.htaccess:

RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

DELETE Setup File (Security Critical!)

SECURITY - YOU MUST DO THIS!
After setup is complete, you MUST delete the setup.php file! If you leave it, anyone could access it and wipe your database.
  1. Open File Manager
  2. Find the setup.php file
  3. Right-click > "Delete"
  4. Confirm deletion

Troubleshooting Common Problems

Problem Solution
500 Internal Server Error 1. Check if .env file exists
2. Check storage/ folder permissions
3. Check error log: storage/logs/laravel.log
404 Page Not Found 1. Check if .htaccess file exists
2. mod_rewrite may be disabled (contact hosting support)
Database Connection Error 1. Verify database credentials in .env
2. Check if database user has ALL PRIVILEGES
Images Not Loading 1. Check if storage link was created (run setup.php again)
2. Check if public/storage folder exists
Session Expires Too Quickly 1. Increase SESSION_LIFETIME in .env
2. Check if storage/framework/sessions/ is writable
Blank White Page 1. Temporarily set APP_DEBUG=true to see the error
2. Fix the error, then set APP_DEBUG=false
!
